2. 当前架构问题分析


2.1 v11/v12多星模型

当前多星实验实际上更接近：

多个观测节点共同估计一个目标状态。


结构：

sat_01 \
         \
          ---> target state
         /
sat_03 /


其中：

sat_01、sat_02、sat_03 表示观测节点。

最终输出：

global_state


数学形式：

目标状态：

x_target


多个节点：

x1,P1

x2,P2

x3,P3


融合：

x_target = Fusion(x1,x2,x3)


该模型适用于：

- 多传感器融合；
- 分布式目标跟踪。


--------------------------------------------------


2.2 v13目标模型

v13需要调整为：

星群中每颗卫星估计自身状态，并通过星间通信实现协同优化。


系统状态：

X={x1,x2,...,xN}


其中：

xi=[ri,vi]


表示第 i 颗卫星自身轨道状态。


最终输出：

sat_01 state

sat_02 state

sat_03 state


而不是：

global_state。

8. Consensus-CI设计


当前 consensus_ci.py 仅为验证demo，需要升级。


目标：

每颗卫星维护：

(xi,Pi)


接收邻居：

(xj,Pj)


采用信息形式：


Y=P^-1


y=Yx


融合：


Yi_new = Σ wiYi


yi_new = Σ wiyi


恢复：


Pi_new=(Yi_new)^-1


xi_new=Pi_new yi_new


要求：

1. 不生成global state；
2. 每颗卫星保持自己的估计结果；
3. 通过通信逐步提高估计精度。
