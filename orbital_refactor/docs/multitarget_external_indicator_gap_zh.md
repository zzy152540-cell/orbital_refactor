# 30星多目标场景外协指标差距审计（开发预扫）

## 1. 当前采用的指标口径

本轮采用《外协指标新.txt》第一组更新指标：不少于25颗卫星；位置、速度、
加速度；光学、红外、雷达；单星多模态和多星协同；单星相对Kalman的RMSE
降幅不低于8%；任一模态时段缺失后的RMSE增幅不超过15%；多星相对单星
平均误差降幅不低于6%；20%节点失效后的平均误差增幅不超过12%；状态同步
延迟不超过100 ms。

开发预扫使用15颗我方观测星和15颗目标星。位置RMSE是主判定量，速度和
加速度RMSE必须同时报告但不混合单位。正式结论至少需要多随机种子、配对
输入和置信区间；本文的单种子或三种子结果只用于定位问题。

## 2. 本轮首先修正的统计口径

原30星场景只启用了很弱的图像读出噪声，却分别按0.2像素、0.25像素和
0.25雷达bin向滤波器报告协方差。3种子、20 s审计中，三种模态的归一化
残差平方均值仅约0.00013至0.00020，报告协方差比实际仿真散布大约5000至
8000倍。旧结果因此过度乐观，不能继续作为指标验收依据。

默认30星前端现已加入与报告精度相同的光学/红外指向抖动和雷达距离/距离率
抖动。重新审计得到：

| 模态 | 归一化残差平方均值 | 95%卡方覆盖率 |
|---|---:|---:|
| 雷达 | 1.022 | 94.86% |
| 红外 | 0.979 | 95.49% |
| 光学 | 0.998 | 95.08% |

三路均接近理论目标1和95%，且平均偏置接近零。该修正改变的是仿真噪声的
真实采样，不是通过缩小协方差人为提高滤波精度。

## 4. 已定位的主要瓶颈

1. 原仿真量测与报告协方差不一致，已修正并通过独立残差审计。
2. 标定后20 s短弧中，雷达单模态终端位置RMSE约2.02 m，红外约4.23 m，
   光学约4441.79 m；多模态本地CI仍给光学约10%至18%的权重，导致融合结果
   明显受短弧角度-only分支影响。需要检查短弧可观测性和CI分支一致性，不能
   仅靠手工调权。
3. CANN在正常量测和纯缺失场景不改变量测，因而有无CANN的RMSE相同；它的
   计算耗时反而显著增加。现阶段先保留接口，不把额外异常场景列为主线。
4. 100 ms是最明确的未达项。需要先剖析原始图像生成、关联/IOD、逐目标本地
   滤波、Consensus-CI和CANN各自耗时，再决定缓存、批处理或降低更新频率的
   具体优化；不能用增大仿真步长伪装满足实时指标。

## 5. 后续顺序

1. 已用校准噪声完成3种子模态时段缺失和3/15节点失效预扫；后续针对未达的
   雷达缺失和实时性指标做定向优化，并继续跟踪节点失效的目标级汇总诊断量。
2. 补齐单星Kalman与待验单星策略的公平配对，并统一目标覆盖率、初始化和
   评分时段，正式计算8%提升。
3. 固化“15个独立我方节点”与固定拓扑Consensus的配对口径，扩展多星6%
   指标到至少5种子。
4. 对单历元路径做性能剖析，优先解决100 ms；CANN单独报告附加耗时。
5. 只有既有指标无法解释CANN作用时，再把偏置、跳变或恢复异常作为补充研究
   场景，不把它加入当前验收主矩阵。

## 6. 2026-10-14 鲁棒性复测结论

本轮先修正了轨迹覆盖口径：双边验收场景显式限制最多15条目标轨迹，
短时漏配进入COASTING/LOST并保留到本轮20 s窗口结束；汇总只有在对照和
受扰组均为15/15、且真值评分无缺样时才允许判定指标。通用在线跟踪器仍以
“目标总数未知”为默认配置。

雷达缺失诊断表明，仅做原有的单节点角度滤波再CI会使位置误差恶化。曾做过
“暂停纯角度更新、只做动力学外推”的诊断，但该路径没有使用光学/红外量测，
不能作为模态缺失鲁棒性验收方案；由该旁路产生的3种子模态缺失结论已经撤销。

当前替代方案是在同一目标、同一时刻已完成关联的光学/红外LOS之间执行
多观测星批量EKF更新。动力学模型只生成先验，后验状态和协方差由各观测星
的位置、LOS量测及其协方差联合修正。每条单站LOS保留径向零空间，但多站
不同视线的组合能够形成三维几何约束。更新完成后再进入既有目标级链路。

联合角度分支现已接入逐流增量CANN：先把关联后的ECI LOS转换为既有SPRI
光学/红外量测，执行CANN预处理，再恢复成ECI单位LOS进入批量EKF。三随机
种子、20 s仿真、6--13 s缺失窗口中，各seed均完成120次目标级多站角度
更新；CANN臂每轮共处理1814--1855条量测。因恢复保护会暂时拒绝部分不可信
角度样本，雷达缺失窗口中CANN臂实际使用569、584和593条光学/红外LOS，
无CANN臂分别使用776、784和800条。

后续逐目标诊断发现，上述公里级控制误差不是合理基线：个别光学角度后验在
短弧弱可观条件下产生数十公里误差，却报告比正确雷达后验更小的协方差，
使基于迹优化的CI选择错误分支。现在本地多模态CI增加可配置的跨模态一致性
门限：雷达后验存在时作为带距离约束的锚点，与其显著不一致的角度后验不进入
该历元CI。角度滤波器的径向零空间保护也改为无论同组是否存在雷达都启用。

修复后完整模态三种子的全程目标RMSE由约2742.89 m、1980.61 m和9610.13 m
下降到2.83 m、2.78 m和2.43 m，均无身份切换，最大瞬时误差约6--8 m。
因此修复前的负增幅结论全部作废。

使用新基线重跑三种子后，CANN臂的光学缺失平均位置增幅约+0.001%，红外
缺失约-0.0004%，均满足15%门限；雷达缺失三个seed分别约+15.63%、
+12.68%和+30.07%，平均约+19.46%，尚未满足指标。三类缺失窗口绝对位置
RMSE均值分别约2.588 m、2.588 m和3.077 m。雷达缺失虽然绝对误差仍为米级，
但相对稳定控制基线的退化现在能够被正确暴露，下一步应优化多站LOS联合更新。

联合LOS链路现已补齐协方差坐标变换：光学像面坐标和红外方位/俯仰角的
二维协方差先通过单位视线雅可比映射为J2000三维秩二协方差，再投影至滤波器
采用的预测视线切平面；CANN前后的SPRI角坐标也采用同一语义完成往返变换。
三种子复测结果分别为+15.63%、+12.69%和+30.04%，平均仍约+19.45%，说明
坐标语义修复是必要的工程正确性修复，但不是剩余指标差距的来源。另行试验的
四次迭代EKF在seed 2上的RMSE与单次EKF相同到微米量级，故不纳入正式实现。
后续应从角度前端统计标定和观测几何可观测度入手，不应任意缩小量测协方差。

进一步的seed 2逐目标几何审计显示，雷达缺失窗口内每个目标仍有3--4颗有效
观测星，三维LOS信息矩阵均满秩；误差最大的目标也不对应最差条件数，因此不是
观测星选择错误或瞬时秩亏。当前角度噪声下，单历元量测信息对应的位置标准差约
1.7--3.2 km，米级精度主要由跨历元动力学先验维持。将过程噪声谱密度由
1e-4降至3e-5后，seed 2控制窗RMSE由2.325 m降至2.312 m，但雷达缺失窗
仍约3.026 m，百分比增幅反而扩大，故不能靠收紧过程噪声达标。当前光学和红外
归一化残差尺度分别约0.998和0.979，也没有人为缩小量测协方差的统计依据。

另实现了默认关闭的8历元因果LOS短窗非线性估计基线，并使用单历元EKF作为
一致性安全回退。seed 2雷达缺失窗RMSE仅由3.023169 m变为3.023123 m，
增幅仍约30.04%；平均处理时间则由约1307 ms增加到1646 ms。该结果说明在
当前短弧、当前角度精度和已有准确动力学先验下，重复重线性化过去LOS几乎不
增加有效信息，因此不应替换正式递推路径。后续若必须满足15%门限，需要明确
额外信息来源（更高角精度、独立距离约束或群体结构约束），而不是继续增加窗口。

当前多站批量更新是小规模验证和性能基线；正式分布式版本还需要明确LOS
量测在固定拓扑中的传输、时间对齐、去重和信息血缘，不能把集中收集量测的
实现直接宣称为最终分布式算法。

seed 2的6--13 s窗口RTN审计进一步定位了雷达缺失退化方向。完整模态的位置
RMSE为R/T/N约1.601/0.476/1.617 m，雷达缺失时为2.262/0.635/1.892 m；新增
位置均方误差约69%来自径向、5%来自切向、26%来自法向。平均三维位置NEES由
1.205升至1.495，仍低于理论均值3，说明当前问题不是协方差过度自信，而是
缺少距离/距离率后径向信息不足。禁用多站联合LOS、仅保留既有单站LOS与CI的
诊断中，seed 2缺失窗RMSE由3.023 m小幅降至3.002 m，增幅由30.04%降至
29.11%，改善不足以达标。下一步应优先验证带协方差传播的历史雷达距离记忆，
而不是继续强化同一批角度量测或缩小协方差。
