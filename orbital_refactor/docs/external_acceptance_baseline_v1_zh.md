# 卫星状态计算软件模块外协指标验收基线 V1

## 1. 目的与边界

本文件将《卫星状态计算软件模块开发外协需求》中的十二项要求转换为可重复、可审计的测试口径。它定义测试方法，不改变现有滤波器、CANN、通信协议或拓扑策略。

当前正式安全基线仍为原有单星联邦-CI和多星分布式估计路径。导航CANN保持可关闭的sidecar；GNN/PPO在通过独立验收前不作为正式外协验收策略。

## 2. 通用测试原则

1. 算法对照必须共享真值轨迹、初始误差、过程噪声、量测噪声、可见性和随机种子。
2. 位置、速度和加速度的RMSE分别计算，不混合不同物理单位。
3. 改进率均使用配对运行计算，再跨场景和随机种子汇总。
4. 开发预扫描至少使用5个种子；正式验收建议至少使用20个种子，并报告95%置信区间。
5. 平均值之外必须报告最差节点、95%分位值和失败运行。
6. 仿真网络时延与软件墙钟处理延迟分开报告。
7. 可视化、CANN sidecar或数据记录开关不得改变算法状态、协方差和量测载荷。

## 3. 状态与误差定义

滤波状态保持六维位置—速度状态：

\[
x=[r_x,r_y,r_z,v_x,v_y,v_z]^T.
\]

加速度不扩展为独立滤波状态，而由估计位置通过当前动力学模型计算：

\[
\hat a_k=f_a(\hat r_k).
\]

对任一状态量 \(y\in\{r,v,a\}\)，全群全时段RMSE定义为：

\[
\operatorname{RMSE}_y=
\sqrt{\frac{1}{NK}\sum_{i=1}^{N}\sum_{k=1}^{K}
\lVert\hat y_{i,k}-y_{i,k}\rVert_2^2}.
\]

同时输出逐节点RMSE、终端误差、95%分位误差和最差节点RMSE。第7至第10项以位置RMSE作为主判定量，速度和加速度RMSE作为强制报告的非劣化辅助量。

## 5. 对照算法定义

### 5.1 P07单星Kalman基线

V1将“单星使用Kalman滤波方法”定义为同一六维轨道状态上的标准单星EKF：顺序处理同一组有效三模态量测，不启用CANN，不建立三个模态局部滤波器，也不执行联邦-CI。

待验单星策略使用三个模态局部估计及原有联邦-CI。量测侧CANN作为独立开关报告；导航CANN不参与该精度改进的归因。

\[
G_{single}=\frac{RMSE_{EKF}-RMSE_{single}}{RMSE_{EKF}}\times100\%.
\]

该定义需要在正式运行前通过项目方口径确认。若合同中的Kalman特指线性KF、单模态KF或其他实现，必须创建新版本基线，不得静默改变V1结果。

### 5.2 P09单星与多星对照

单星模式中每颗卫星独立运行，不接收邻星状态；多星模式启用星间相对观测、状态通信、Schmidt更新与回放，并使用冻结的确定性安全拓扑。两者共享20星物理条件和随机输入。

\[
G_{multi}=\frac{RMSE_{single}-RMSE_{cooperative}}
{RMSE_{single}}\times100\%.
\]

## 6. 鲁棒性场景

### 6.1 R08单模态缺失

正式主场景为单一模态全程缺失，并分别测试OPTICAL、INFRARED和RADAR。中段连续缺失与间歇缺失作为扩展场景。

\[
D_m=\frac{RMSE_{missing\ m}-RMSE_{full}}
{RMSE_{full}}\times100\%\le20\%.
\]

### 6.2 R10节点失联

20星中选择4星，失联窗口内删除这些节点的所有入站和出站通信边，本地传感器与本地滤波继续运行。至少覆盖同轨道面连续节点、跨轨道面分散节点、高中心性节点和随机节点组合。

\[
D_{node}=\frac{RMSE_{disconnected}-RMSE_{normal}}
{RMSE_{normal}}\times100\%\le15\%.
\]

分别报告全群、失联4星及其余16星的误差。20%随机丢包不能替代20%节点失联测试。

## 7. 更新频率与同步延迟

P06采用0.2 s外部滤波步长，在20星、三模态和正式多星策略下运行。计时排除GUI刷新和录像写盘，并分别报告无CANN、代表节点CANN和全节点CANN配置。

至少输出平均、P95、P99、最大单历元耗时、超过200 ms的历元比例和实时因子。合同硬判定使用平均更新频率：

\[
f_{mean}=\frac{K}{T_{wall}}\ge5\ \mathrm{Hz}.
\]

P11使用单调墙钟，在消息产生和接收端完成状态应用处埋点：

\[
L_i=t^{applied}_i-t^{created}_i,
\qquad \overline L\le150\ \mathrm{ms}.
\]

同时报告P95和最大延迟，并区分普通更新、历史回放和显式重同步。配置中的秒级仿真链路时延属于故障条件，不等同于软件处理延迟。

## 8. 第一版正式测试矩阵

- 规模：5、10、20星；核心合同项以20星判定。
- 时长：开发预扫描120 s；正式测试1200 s或1800 s。
- 步长：精度矩阵使用冻结配置；P06固定使用0.2 s。
- 构型：固定Walker基线和随机化Walker扩展集。
- 种子：开发5个；正式不少于20个。
- 条件：正常、三类单模态缺失、单/双导航失效、20%节点失联、丢包、时延、链路恢复和组合退化。

1. 将本文件和机器可读阈值作为V1基线评审冻结。

## 11. P07首轮开发预扫描

现有配对入口为：

```bash
python -m experiments.run_external_single_accuracy_acceptance \
  --seeds 0 1 2 3 4 --duration 120 --dt 2 \
  --output results/external_acceptance/p07_single_accuracy_prescan_120s
```

集中式EKF与联邦-CI对每个seed重新生成同一确定性真值和同一量测实现，均关闭CANN且不注入模态缺失。初查发现历史单星构型中的目标位于光学相机负深度方向，导致光学量测全部被可见性规则标记为无效；该结果不能称为三模态验收。P07入口因此显式采用目标处于正SPRI深度的配对构型，同时保留历史实验的默认构型不变。

修正后的首轮5种子、120 s三模态开发预扫描得到：

- 平均位置RMSE改进率约为-2.242%，未达到5%阈值；
- 近似95%半宽约为3.507个百分点；
- 5个种子中1个改善、4个退化，逐种子改进率约为+2.313%、-0.111%、-0.502%、-6.124%和-6.788%；
- 初始三分之一时段平均位置改进约为+0.853%，稳定时段约为-12.925%；
- 平均速度RMSE改进率约为+16.971%；
- 平均加速度RMSE改进率约为-1.471%；
- 三模态NIS均有限，两条架构的硬拒绝计数均为0；
- 联邦-CI平均权重约为光学0.634、红外0、雷达0.366。

进一步读取CI反馈前的局部后验后，三条支路的平均位置RMSE约为光学16.05 m、红外18.60 m、雷达17.96 m；平均协方差迹约为光学804.01、红外954.13、雷达940.39。trace-CI优先选择光学、排除红外与这一协方差排序一致，暂未发现明显的权重实现错误。滤波器原有reset feedback会在融合后覆盖公开局部历史，本轮仅增加融合前历史的只读诊断副本，不改变运行状态。

该结果只属于开发预扫描，样本数未达到正式20种子要求；但现有证据明确不支持宣称P07已经通过。当前主要问题不是量测拒绝或CI权重程序错误，而是比较定义本身：在同一量测噪声相互独立且模型已知的仿真中，集中式EKF可以联合累积三模态信息，CI则必须对未知相关性保持保守，理论上不应预期CI稳定优于前者。正式扩大运行前必须确认合同中的“单星Kalman”究竟指单模态传统KF，还是使用相同三模态的集中式EKF；不得仅为达到5%阈值调整算法或测试口径。

作为并列合同口径，入口随后加入仅光学、仅红外、仅雷达三个集中式EKF，并以每个配对seed中RMSE最低的单模态结果作为严格参考。相同5种子、120 s预扫描中，最佳单模态全部为光学；三种单模态平均位置RMSE分别约为光学28.22 m、红外42.72 m和雷达71.49 m，联邦-CI相对逐seed最佳单模态的平均位置RMSE改进约为41.93%，5个seed全部超过5%阈值。近似95%半宽约为16.37个百分点。该结果达到数值阈值但未满足正式20种子样本门，因此`threshold_met=true`而`passed=false`。

这组结果说明“多模态策略相对单模态Kalman”具有较充分的初步可行性，而“联邦-CI相对同信息三模态集中式EKF”不具备同样结论。两种口径必须在报告中并列保留，最终合同判定仍需项目方确认Kalman基线含义。

## 12. P08首轮开发预扫描

P08使用与P07相同的正深度构型、联邦-CI和5个配对seed，CANN保持关闭。每次将一种模态从0 s至120 s全程标记为无效，并与同seed完整三模态结果比较：

```bash
python -m experiments.run_external_single_robustness_acceptance \
  --seeds 0 1 2 3 4 --duration 120 --dt 2 \
  --output results/external_acceptance/p08_single_robustness_prescan_120s
```

首轮位置RMSE增幅为：

| 全程缺失模态 | 平均增幅 | 近似95%半宽 | 最差seed | 20%阈值 |
|---|---:|---:|---:|---|
| 光学 | 98.02% | 48.26个百分点 | 166.61% | 未达到 |
| 红外 | 约0% | 约0个百分点 | 约0% | 达到 |
| 雷达 | 90.20% | 64.52个百分点 | 212.35% | 未达到 |

该结果与P07的CI权重一致：完整三模态融合主要使用光学和雷达，红外平均权重为0，因此移除红外没有可测影响；光学与雷达之间仍存在显著互补，移除任一都会退化。当前结果不支持宣称P08通过。

为区分量测链路故障与信息冗余不足，R08记录进一步加入各模态有效数、完整/缺失场景平均CI权重及三个局部分支的位置RMSE。5种子完整场景的平均CI权重约为光学0.634、红外0、雷达0.366。缺失光学后，剩余红外和雷达各有61个有效样本，权重约转为0.860和0.140，但两个局部分支平均RMSE均约31 m；缺失雷达后，光学仍有61个有效样本且权重约为1，但平均局部RMSE约28 m。完整融合平均RMSE约15.66 m。由此可排除“剩余量测未生成或未进入融合”，并确认当前场景依赖光学与雷达的互补约束。

另用3个种子对全程120 s缺失执行现有`trace/logdet × reset_feedback开/关`聚焦扫描。四种组合下，缺光学平均增幅约86.9%至139.4%，缺雷达约111.5%至116.4%，均未达到20%门限；关闭回灌或切换CI目标函数不能解决问题。因而下一步不应继续盲调CI选项，而应检查验收所指的缺失持续时间，并评估是否需要增强红外方向量测几何、增加绝对导航约束或设计明确的退化模式。任何改进都必须继续与冻结参考严格配对。

随后使用正式光学像面、红外方位俯仰、雷达距离/距离率模型及其协方差，对120 s真值轨迹构造尺度化有限时域可观测矩阵。状态尺度固定为位置1000 m、速度1 m/s，数值秩相对阈值固定为`1e-6`，状态转移和量测Jacobian均调用现行滤波器的固定步长线性化。光学与红外量测Jacobian的平均及最小行空间重合度均为1.0；二者叠加的瞬时秩仍为2，说明它们只是同一视线方向约束的不同参数化，并未增加独立方向。光学加雷达的瞬时秩为4，有限时域最弱奇异值约24.10、条件数约45.87；红外加雷达虽也达到有限时域六维数值满秩，但最弱奇异值仅约3.06、条件数约84.99。三模态最弱奇异值约24.36，几乎等同光学加雷达。

将红外标准差缩小至基线的0.25倍后，红外加雷达的最弱奇异值提高到约12.09，但仍低于光学加雷达；放大至2倍后则下降到约1.53。需要注意，单一模态经过轨道动力学累积后也可能显示六维数值满秩，但极小的最弱奇异值和很大的条件数表示其实际估计强度很弱，不能将“满秩”直接解释为鲁棒。该结果与RMSE、CI权重诊断一致：当前红外没有提供独立于光学的新几何维度，且精度明显更弱；若合同要求光学全程缺失仍保持20%以内，仅调CI权重无法实现，必须引入真正不同的观测几何或额外独立信息。

作为不改变正式滤波的候选，影子模型在红外Az/El后加入`log(2*atan(D_eff/(2*rho)))`视角尺寸量测。它使红外瞬时秩由2提高到3；雷达缺失时，光学加增强红外的有限时域最弱奇异值相对原光学加红外提高约43至210倍，证明径向信息在数学上有效。但在当前105至109 km相对距离、10 m有效目标直径和300像素焦距下，目标视角尺寸仅约92至95微弧度，即约0.028像素，远低于当前1.2像素PSF。因此该结果只是理想可行性上界，不能直接接入滤波或作为当前硬件能力声明。

针对光学缺失，进一步将红外角标准差从基线0.05度向下扫描，并为每个候选精度重新生成同seed完整参考与光学全程缺失组。5种子、120 s结果中，0.025度的平均RMSE增幅仍约42.16%；0.0125度平均约14.55%，但最差seed仍约30.10%；0.00625度平均约2.89%、最差seed约6.31%；0.005度平均约1.06%。因此若要求每个开发seed均稳定低于20%，当前场景需要约0.00625度量级，即相对现配置约8倍的红外角精度提升。该数值是传感器/前端设计目标而非已实现能力；后续必须通过焦距、视场、信噪比和亚像素质心误差的原始图像仿真验证。

原始点源前端进一步对300、600、1200和2400像素焦距，0.8/1.2像素PSF及峰值SNR 20/100/1000执行各200次随机亚像素相位Monte Carlo。当前300像素焦距、1.2像素PSF下，SNR 1000的经验角RMSE约0.00087度，SNR 100约0.00762度；600像素焦距、SNR 100时约0.00387度。当前120 s相对角漂移下，所有扫描焦距的固定初始视线视场覆盖率均为100%。因此0.00625度在当前简化前端中存在可行配置，现行0.05度更接近保守固定报告值，而不是高SNR质心提取器的经验误差。

但该图像模型目前只有固定高斯点源、固定背景和加性读出噪声，尚未包含光子噪声、热背景漂移、杂散光、姿态抖动、焦面畸变、标定偏差和目标强度变化。故不能据此直接缩小正式红外协方差。下一阶段应把这些误差源至少以参数化形式加入原始图像Monte Carlo，并由经验残差标定随SNR和焦面位置变化的协方差；只有扩展模型下仍能稳定达到目标，才进入滤波影子接入。

首轮扩展仅作用于红外焦平面前端，加入可选的光子散粒噪声、逐帧热背景漂移、二维指向抖动、一阶径向畸变和固定像素标定偏差；所有开关默认关闭，关闭时沿用原渲染路径，光学、雷达、EKF和CI均未改动。300次Monte Carlo覆盖300/600像素焦距、峰值100/1000、中心/离轴位置。0.00625度目标下，简化基线8格中6格达到，光子噪声组4格达到，中等综合误差组仅600像素焦距且峰值1000的中心与离轴2格达到（角RMSE约0.00559和0.00598度），强退化组无一达到。中等综合误差在300像素焦距、峰值1000时约0.0106度，在600像素焦距、峰值100时约0.0153至0.0159度。因此原简化模型确实偏乐观，焦距和光子统计均会影响可行性，不能直接把0.00625度写成固定红外协方差。

本轮各误差幅值采用未标定的开发敏感性假设，只能用于识别瓶颈与筛选配置，不能作为硬件性能声明。下一步应先将经验残差按SNR、焦距和焦面位置形成协方差查表或回归模型，再以影子模式接入红外量测协方差；在获得真实相机参数前，暂不把同类误差模型扩展到光学或雷达。

已进一步建立显式可选的红外经验协方差表，按焦距、峰值SNR及中心/离轴区域匹配二维Az/El协方差；未提供标定表时仍严格使用原`reported_centroid_sigma_pixels`路径。使用seed 0的300次样本标定、seed 101的300次独立样本验证，中等综合误差下原固定协方差的平均NIS仅约0.05至0.45，95%门限超限率全部为0，说明原0.25像素固定报告值明显保守。经验协方差将平均NIS调整到约1.93至3.42，接近二维量测理论均值2；对应95%门限超限率约5%至17.3%。其中300像素焦距、峰值100的中心格达到平均NIS 1.93、超限率5%，而600像素焦距、峰值1000的离轴格仍为3.42和17.3%。

该独立验证说明经验协方差方向正确，但仅靠随机协方差不能完全处理固定像素偏差及离轴系统误差。后续滤波影子对照前，应把前端标定拆成两项：由独立标定集估计并扣除确定性偏差，再用去偏残差估计协方差；两者均保持显式开关且默认关闭。否则直接用含偏残差调整R会把系统误差误当作随机噪声，并导致NIS和门控解释失真。

偏差校正随后作为第二个显式开关加入标定表。独立样本中，600像素焦距、峰值1000的离轴格由仅经验协方差的平均NIS 3.42、95%超限率17.3%，改善为去偏后的2.13和7.3%；300像素高SNR离轴格由2.66和11%改善为2.03和5.7%。其余格点去偏后平均NIS约1.90至2.32，证明“先去确定性偏差、再描述随机残差”的分层方式比单纯膨胀R更合理。

在20 s Walker多星原始红外图像链路上进一步完成三路滤波影子接入。固定报告协方差、仅经验协方差、去偏加经验协方差的位置RMSE分别约2.36838 m、2.36544 m和2.36763 m，差异很小；红外平均NIS则分别约0.0621、2.536和2.046。该结果说明当前标定主要修正统计一致性，并未制造不合理的RMSE收益。由于时长短且光学、雷达仍同时参与，本结果只证明接口可用和方向合理，不能作为P08改进结论；下一步需要多seed、较长时段及光学缺失条件下的配对影子测试。

Walker网络上的3种子120 s光学缺失补充实验显示三种标定臂的RMSE变化均仅约正负0.007%，原因是该网络场景保留全节点绝对导航及其他星间信息，而且不包含单星联邦-CI权重。该结果只保留为接口回归，不能替代P08。随后将红外原始图像前端接入真正的单星三分支联邦-CI：虚拟相机采用跟踪光轴指向当前真实视线，焦平面提取的是相对跟踪中心的角残差，再映射回SPRI方位/俯仰；此真值指向属于传感器仿真与标定假设，并已在元数据显式标记，不进入滤波预测。

3种子、120 s单星配对影子中，固定0.25像素报告协方差时光学全缺失的平均RMSE增幅约1.46%、最差约3.94%，但红外平均NIS仅0.056，且完整场景红外CI权重为0。改用经验协方差后平均增幅约0.00010%、最差约0.00039%，光学缺失时红外NIS约1.70、CI权重约0.528；去偏经验协方差结果相近，平均增幅约0.00009%、最差约0.00056%，红外NIS约1.70。该结果表明600像素焦距、峰值1000的开发配置使红外支路精度足以在CI中承担主要方向约束，从而令光学近似冗余。

但这仍不是正式P08通过证据：当前焦距、光子计数、热背景、抖动和固定偏差均为开发假设，跟踪光轴也使用真值指向；3个seed不足正式样本量。后续应加入姿态指向误差或滞后预测光轴，并用真实或需求级相机参数重新标定，再执行不少于正式要求种子的长时配对测试。只有此时仍满足20%门限，才能把红外原始图像标定路径提升为候选正式配置。

已补充第一阶段滞后预测光轴：先分别运行与完整/光学缺失条件相匹配的解析量测跟踪器；在历元`k>0`仅取该跟踪器`k-1`后验并按恒速外推至`k`，首历元使用配置的初始误差。该方式仍是分阶段影子验证，不是最终在线闭环，但避免了使用当前历元真值更新结果。滞后光轴平均误差约0.087至0.099度、最大约0.098至0.147度，红外有效率均为100%。

首轮预热扫描曾出现seed 2约36.84%的异常退化，但因果审计发现60 s才开始缺失时，0至58 s两组滤波状态已提前分叉。根因是红外泊松图像和雷达量测共用同一随机数发生器：60 s后的红外光轴变化改变了整段图像生成消耗的随机数数量，继而使随后批量生成的雷达噪声连0 s样本也不同。修复为原始红外专用确定性随机流后，新增“缺失开始前状态逐元素严格相等”回归约束。

因果修复后的3种子120 s结果中，全程光学缺失的RMSE增幅分别约-1.32%、0.27%和2.26%；从20 s开始缺失约-0.05%、-0.07%和0.33%；从40 s开始约-1.02%、0.64%和2.33%；从60 s开始约-0.30%、0.07%和0.05%。所有组合均远低于20%开发门限，说明约0.09度滞后光轴误差尚未破坏当前600像素、高SNR红外候选配置。该结论仍限于3种子、分阶段跟踪器和假设相机参数，不能替代正式长样本在线闭环验收。

精确中心真值指向臂仍表现出局部角度滤波病态，因此已明确降级为诊断项，不参与滞后光轴性能结论。当前证据不足以将其唯一归因于亚像素相位，后续应单独检查固定偏差、极小协方差与角度EKF/CI耦合；不应因该诊断直接扩展三模态误差模型。

随后在保持滤波状态、EKF、CI及默认配置不变的前提下，将同级参数化误差边界扩展到另外两个原始前端。光学增加可选的光子噪声、杂散光背景漂移、指向抖动、一阶径向畸变和固定焦面偏差；雷达距离—多普勒图增加可选的背景漂移、回波幅度波动、距离/距离率随机抖动及固定偏差。所有新增项默认关闭，诊断元数据明确记录实际注入值。

200次Monte Carlo误差预算表明，原固定报告协方差在简化及中等误差条件下总体偏保守；雷达强误差工况则出现平均NIS约4.31至4.59，说明固定偏差与强抖动存在时，固定协方差可能转为偏乐观。因此不得对三模态统一使用单一倍率，而应按模态、空间工作点和SNR分别标定，并将随机协方差与固定偏差分开处理。

使用seed 0的300个样本标定、seed 101的300个独立样本验证中等综合误差。光学中心高SNR和偏轴低SNR在“经验协方差+显式偏差修正”下平均NIS分别约1.91和2.26，95%门限超限率约4.67%和6.33%；雷达中心高SNR和偏移低SNR平均NIS分别约1.87和1.81，超限率均约3.67%。仅替换经验协方差而不修正固定偏差时平均NIS约2.36至3.05，表现出系统偏差残留。

进一步在3个配对seed、120 s Walker场景中仅替换目标模态原始量测及其协方差。光学去偏经验标定将平均NIS由约0.094调整为2.183，平均位置RMSE约由1.497 m变为1.497 m，基本不变；雷达将平均NIS由约0.739调整为2.116，平均位置RMSE约由1.500 m变为1.491 m，相对位置RMSE约由1.946 m变为1.951 m。仅经验协方差但不去偏的雷达臂平均位置RMSE约1.546 m，明显差于另外两臂。因此当前候选必须同时显式处理已标定固定偏差，但仍只作为可选研究配置，不替换正式固定协方差基线，也不作为硬件性能声明。

全程缺失场景下，CANN不能生成新的独立信息，不能预期依靠短期状态保持将120 s退化压缩到20%以内。下一步应先检查合同中的“单一观测模态缺失”是全程缺失还是有限时段中断，并在不改变主判定记录的前提下，对CI目标、局部滤波可观测性和有限缺失时长进行专项扫描。

### 12.1 有限缺失与CI策略扫描

3个种子、120 s场景进一步扫描10/20/40/60 s中段缺失、trace/logdet目标和reset-feedback开关。现行默认reset-feedback开启时，两种CI目标下所有模态和所有扫描时长的平均位置RMSE增幅均不超过20%；trace目标的最大平均增幅约为缺光学60 s时的8.50%，logdet目标的最大平均增幅约为缺雷达20 s时的8.11%。个别负增幅属于短样本噪声波动，不解释为缺失改善性能。

关闭reset feedback后，缺雷达10/20/40/60 s的平均增幅在trace目标下约为23.71%、46.13%、65.68%和82.52%，均超过阈值；缺光学在60 s时也超过阈值。logdet呈现相同趋势。因此现有证据表明局部滤波器每历元接收融合反馈是有限缺失鲁棒性的关键机制，而trace与logdet差异较小。

当前应并列保留两项结论：现行默认架构初步满足最长60 s的有限时段单模态中断，但不满足120 s全程缺失。正式合同验收必须先确认“缺失”的持续时间或占空比；在此之前不得用有限时段结果替代永久缺失结果。

### 12.2 量测侧CANN边界审计

3个种子、60 s中段缺失的无故障配对中，缺失窗口内有无CANN的位置RMSE差严格为0，因为预处理器不会为无效量测合成替代观测。正常恢复阶段，光学和雷达CANN反而分别平均增加约0.62 m和1.10 m，红外差异可忽略。因此当前CANN不能作为P08纯缺失指标改善的依据。

在恢复后的前两个样本注入脉冲异常后，CANN体现出不同作用：无CANN时光学恢复异常带来的附加RMSE平均约3574.56 m，启用CANN后约0.75 m；雷达由约103.06 m降至约-1.35 m的短样本净变化，平均抑制约104.41 m。红外因CI权重接近0而没有可测影响。

因此量测侧CANN的已验证定位是“恢复异常抑制与可信重捕获”，不是“缺失信息预测或补全”。负的净异常代价属于配对短样本波动，不解释为异常改善精度。后续验收必须分别报告纯缺失、正常恢复和带异常恢复，不能合并成一个鲁棒性数字。

## 13. P09首轮开发预扫描

P09使用同一Walker 20/10/1场景进行严格配对。每个seed只生成一次真值、初始误差和绝对导航量测：单星独立组关闭全部星间相对量测和邻星状态消息，仅保留各节点自身动力学与绝对导航滤波；多星协同组启用现有RADAR、INFRARED、OPTICAL星间量测、Schmidt更新和精确事件回放。因此两组之间唯一的算法差异是协同信息链路。

```bash
python -m experiments.run_external_cooperative_accuracy_acceptance \
  --seeds 0 1 2 3 4 --duration 120 --dt 2 \
  --output results/external_acceptance/p09_cooperative_accuracy_prescan_120s
```

5个种子、120 s、2 s步长的开发预扫描结果为：单星独立组全群平均位置RMSE约1.645 m，多星协同组约1.468 m，逐seed改善率平均10.674%，近似95%半宽约2.517个百分点，最差seed改善7.801%。5个seed均超过5%数值门限，因而`threshold_met=true`；但样本数未达到正式要求的20个seed，故`formal_sample_size_met=false`且`passed=false`。

全群均值改善不保证每一颗卫星均改善。100个配对节点样本中有24个节点退化、29个节点未达到5%改善；最明显的退化为seed 3的`sat_p01_s02`，约为-42.54%。同一seed中，协同组的最差节点RMSE约2.139 m，高于独立组约1.976 m。该现象不改变当前P09“全群平均RMSE”口径的预扫描结论，但正式报告必须同时保留逐节点和最差节点指标，后续还应检查受损节点、几何位置及其邻接关系。

逐节点第一层审计表明，当前持久拓扑中20个节点度数均为2，每个节点在120 s内均收到122条RADAR、122条INFRARED和122条OPTICAL有效量测，因此退化不能归因于少邻居或量测缺失。改善率与总体、雷达、红外、光学平均NIS的相关系数分别约为0.014、-0.013、0.100和-0.066，未呈现明显创新异常关系；与独立组初始性能水平的相关系数约为0.354，说明独立估计本来较好的节点更容易出现负收益。跨5个seed平均后，`sat_p01_s02`和`sat_p03_s01`仍分别约退化7.71%和5.71%，下一层诊断应重点检查这两个固定轨道位置的视线方向条件、邻星组合和分方向误差，而不应直接按全局NIS调门限。

第二层几何与时段分解进一步表明，全体节点改善率与平均邻星距离和两条视线夹角的相关系数仅约-0.076和-0.078，不能用单一距离或夹角解释退化。`sat_p01_s02`连接`sat_p02_s02`与`sat_p10_s01`，其退化主要集中在前1/3时段：初段平均约-20.83%，后2/3时段转为约+9.04%，且主要体现在径向误差，属于明显的初始化/收敛瞬态。`sat_p03_s01`连接同轨道面的`sat_p02_s01`与`sat_p04_s01`，初段和后段分别约-5.99%和-7.66%，同时沿轨与法向误差增加，属于持续性局部负收益。下一步应对`sat_p03_s01`分别执行逐邻边和逐模态消融，定位具体信息来源；对`sat_p01_s02`则优先检查启动阶段的邻星先验与首次回放，不应将两类退化混为同一问题。

### 13.1 `sat_p03_s01`定向消融

保持其余19个节点及其协同链路不变，只改变`sat_p03_s01`接收的邻星与模态。5个seed稳定时段的平均改善率为：完整三模态-7.66%，仅RADAR -7.64%，仅INFRARED约-0.01%，仅OPTICAL约0.00%；因此该节点的可见负收益几乎全部由RADAR相对距离/距离率更新决定，角度模态在当前约5000 km量级链路和噪声配置下基本不改变结果。

逐边结果不支持永久删除某一固定邻边：仅保留`sat_p04_s01`时平均为-4.94%，仅保留`sat_p02_s01`时平均为-10.10%，但不同seed中造成主要退化的邻边会互换。例如seed 0和3中保留`sat_p04_s01`可恢复到接近独立基线，而seed 1中同一选择仍退化约43.46%。这说明问题更像是“当前先验和几何条件下，某次雷达协同更新是否具有正净信息增益”，而不是静态节点编号本身有缺陷。后续应以预测协方差和量测Jacobian形成的预期信息增益或后验协方差变化作为确定性选边依据，并将NIS保留为异常门控；不应依据本轮结果硬编码删除某条边。

### 13.2 预测信息增益的判别能力审计

在不改变更新接受逻辑的前提下，针对`sat_p03_s01`的610次RADAR更新记录更新前活动协方差、增益、创新协方差，并计算理论位置协方差缩减量`trace(KSK^T)`及其相对先验位置协方差的比例；运行后才使用真值计算同一次更新前后的位置误差范数变化。真值误差仅用于离线审计，不进入滤波器或策略输入。

结果显示，预测协方差缩减比例与实际位置误差变化的相关系数仅约-0.041；低收益四分位与高收益四分位的瞬时误差变差比例分别约48.4%和49.0%，没有可用区分度。两条邻边的变差比例也均约50%，平均单次误差变化分别约-0.0048 m和+0.0013 m。该结果符合随机Kalman更新的性质：协方差缩减描述统计期望，不保证每次噪声实现都降低真值误差。

因此预测信息增益仍可作为资源受限时的候选边排序特征，但当前证据不支持把它直接作为“负更新拒绝门”。P09局部长期退化更可能来自有限样本下的更新序列累积以及绝对导航已较强时的边际收益波动。下一步应验证更长时长和更多seed下固定节点负收益是否持续，并比较全群均值、逐节点尾部和协方差一致性；只有持续存在统计性偏差时，才需要设计新的质量反馈或选边规则。

### 13.3 扩展样本与时长检查

20个seed、120 s测试中，单星独立与多星协同的全群平均位置RMSE分别约为1.645 m和1.467 m，配对平均改善10.812%，近似95%半宽1.289个百分点，最差seed仍改善6.735%。数值门限和20个seed样本量门限均达到，但正式时长门限未达到，因此运行器已修正为`threshold_met=true`、`formal_sample_size_met=true`、`formal_duration_met=false`、`passed=false`，避免把开发短测误报为正式验收。

该20-seed短测的400个节点配对样本中，99个节点退化、134个节点未达到5%改善。此前的`sat_p01_s02`跨seed均值回升至约+8.22%，确认其5-seed负值主要是小样本波动；`sat_p03_s01`回升至约+2.16%，但20次中仍有11次退化，属于高波动、低边际收益节点，而非明确的稳定负偏节点。

5个seed、600 s中间长测的全群平均改善为9.971%，近似95%半宽1.965个百分点，最差seed改善6.797%。100个节点配对样本中22个退化、31个未达到5%，与120 s五种子时的24%和29%相近，说明逐节点尾部负收益不会仅靠延长到600 s完全消失。`sat_p03_s01`平均仍约退化0.86%，5次中3次退化，但幅度已经较小。当前证据支持“现有协同链路稳定改善全群平均误差”，不支持“每颗卫星均改善”。正式20 seed、1200 s测试应作为独立长批处理执行，并在结论中同时保留全群门限与逐节点尾部统计。

## 15. P06更新频率首轮开发扫描

P06入口固定使用Walker 20/10/1、0.2 s外部滤波步长和现行三模态网络滤波链路，排除GUI刷新与录像写盘：

```bash
python -m experiments.run_external_update_frequency_acceptance \
  --seeds 0 1 2 3 4 --duration 20 --dt 0.2 \
  --output results/external_acceptance/p06_update_frequency_prescan_20s.json
```

核心滤波通过可选回调记录每一个历元的真实墙钟耗时；该回调默认关闭，不改变滤波历史、状态或协方差。代表节点CANN与全节点CANN目前仍由离线历史适配器批量构造，因此只能将整段CANN耗时均摊到各历元，分别标记为`filter_per_epoch_plus_run_amortized_cann`，不得解释成在线CANN的真实逐历元P95/P99。

5个种子、20 s开发扫描结果如下：

| 配置 | 平均频率 | 平均历元耗时 | P95 | P99 | 最大值 | 超过200 ms比例 |
|---|---:|---:|---:|---:|---:|---:|
| 核心滤波，无CANN | 5.553 Hz | 179.338 ms | 247.094 ms | 299.366 ms | 398.633 ms | 24.158% |
| 代表节点CANN | 5.411 Hz | 184.035 ms | 251.611 ms | 303.892 ms | 403.298 ms | 26.535% |

加入严格受限的当前历元传输快路径后，核心滤波逐seed平均频率约为5.553、5.627、5.470、5.660和5.453 Hz，5个种子均达到5 Hz平均频率门限，因此以无CANN核心滤波为正式判定配置时`passed=true`。代表节点CANN也初步达到门限；全节点离线CANN历史构造仍未达到门限，且其耗时只是整段均摊口径。P95和P99仍超过200 ms，表明平均频率通过不代表所有历元均能在200 ms内完成，尾部延迟必须继续保留在报告中。

下一步应先对核心滤波逐历元路径进行性能剖析，重点区分状态消息精确事件回放、三模态Schmidt更新和诊断历史构造的耗时；随后将CANN改为在线增量更新后再复测全节点配置。不得通过放大`dt`满足P06，因为该指标固定要求0.2 s步长。

### 15.1 核心链路受控耗时消融

新增嵌套消融入口，在相同真值、初始误差和量测实现下依次运行：完整精确回放三模态链路、关闭状态消息回放但保留三模态Schmidt更新、仅保留动力学与绝对导航。该消融只定位计算成本，不比较三组精度，也不建议改变正式算法配置。

5个种子、4 s短测中，三组平均历元耗时分别为165.550、90.620和39.779 ms。据相邻配置差值，精确回放增量约74.930 ms/历元，三模态相对更新增量约50.841 ms/历元。函数级剖析与该结果一致：状态消息批处理会触发事件回放，主要底层成本来自重复的数值状态转移Jacobian和RK4轨道传播，而非诊断字典维护。

由于4 s尚未填满10 s回放窗口，又补充了seed 0、20 s消融。三组平均历元耗时分别为208.902、95.096和40.717 ms；精确回放增量上升到113.806 ms/历元，三模态相对更新增量为54.379 ms/历元。原5种子P06记录按历元分段后，0--5 s、5--10 s、10--15 s和15--20 s的核心平均耗时约为199.794、277.125、250.538和219.885 ms，说明回放窗口填充阶段成本上升，裁剪后回落，没有观察到无限增长。

因此性能修正顺序冻结为：首先优化精确回放内部的重复传播与状态转移计算；其次评估三模态量测Jacobian的安全缓存或解析实现；最后才考虑诊断历史压缩。任何优化都必须保持精确传输、回放结果和默认关闭计时回调时的回归结果不变。

### 15.2 当前历元精确传输快路径

正式网络循环会先将协调器预测到当前历元，再接收引用上一检查点、但新增事件全部位于当前历元的状态消息。旧实现仍从上一检查点重新传播，造成重复的数值Jacobian与RK4计算。当前实现仅在“本批存在新增事件、所有新增事件均位于当前历元、当前历元尚未应用本地观测或远端事件”三个条件同时满足时，从当前先验执行零跨度回放；任何延迟、补发、混合时标、同历元观测已应用或逐条消息交叉情况均自动保留原完整回放。

专项回归覆盖精确传输、事件回放、消息顺序无关性、延迟链路、拓扑重同步和资源窗口。优化后相同5种子、20 s P06配置中，核心平均历元耗时由约236.469 ms降至179.338 ms，平均频率由约4.279 Hz升至5.553 Hz。该结果支持核心滤波达到合同平均5 Hz门限，但不将全节点离线CANN配置宣称为通过。

## 16. P11状态同步延迟首轮开发扫描

P11使用在线`NetworkSchmidtOrchestrator`闭环，在状态消息完成构造、进入接收处理以及接收端应用完成处读取`time.perf_counter`单调墙钟。墙钟诊断默认关闭；开启后只向消息诊断记录增加计时字段，不修改状态消息协议、滤波状态或协方差。

```bash
python -m experiments.run_external_state_sync_latency_acceptance \
  --seeds 0 1 2 3 4 --duration 4 --dt 0.2 \
  --output results/external_acceptance/p11_state_sync_latency_prescan_4s
```

扫描严格区分四类记录：完全正常、零仿真延迟的普通更新；带0.4 s仿真链路延迟的历史回放；链路恢复时的新lineage显式重同步消息；重同步场景中未受影响链路的背景普通流量。只有第一类进入合同150 ms硬判定，仿真链路秒级延迟单独记录，不与软件墙钟相加或互相替代。

| 类别 | 消息数 | 创建到应用平均值 | P95 | 最大值 | 接收到应用平均值 | 平均仿真链路延迟 |
|---|---:|---:|---:|---:|---:|---:|
| 普通更新 | 4200 | 85.068 ms | 174.245 ms | 300.639 ms | 84.569 ms | 0 s |
| 历史回放 | 1400 | 699.967 ms | 1233.118 ms | 1913.430 ms | 514.791 ms | 0.4 s |
| 显式重同步 | 10 | 17.043 ms | 26.697 ms | 26.871 ms | 16.159 ms | 0 s |
| 重同步背景流量 | 4120 | 79.868 ms | 164.061 ms | 219.332 ms | 79.385 ms | 0 s |

普通更新平均值低于150 ms，因此`threshold_met=true`。端点诊断曾发现seed 2存在最大绝对值约`1.78e-10`、相对Frobenius误差约`2.86e-10`的协方差舍入差，均值误差为0；通过“逐元素安全下限与整体相对误差双重判定”，并在兼容后仅将邻星协方差块钉合到发送端ACK基线，普通组恢复为4200/4200全部接纳，重同步场景也无协议拒绝，因此`protocol_clean=true`。真实协方差篡改测试仍必须被拒绝。

当前只有5个独立种子且时长仅4 s，未满足正式不少于20个种子和1200 s时长要求，因此`formal_sample_size_met=false`、`formal_duration_met=false`、`passed=false`。P95与最大值超过150 ms也必须保留为尾部风险，不能被平均值掩盖。

历史回放的接收后处理耗时显著高于普通更新，说明延迟消息触发的完整历史重放仍是主要实时性风险。修复延迟消息将旧端点协方差误写入当前传播状态、却未精确钉住历史ACK端点的问题后，历史回放恢复为1400/1400全部接纳；三个场景均无协议拒绝。墙钟结果对机器瞬时负载敏感，正式测试需要固定机器状态、预热并重复运行。显式重同步本身在当前短测中不是主要瓶颈。
