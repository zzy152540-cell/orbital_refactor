# 卫星状态计算软件模块外协指标验收基线 V1

## 1. 目的与边界

本文件将《卫星状态计算软件模块开发外协需求》中的十二项要求转换为可重复、可审计的测试口径。它定义测试方法，不改变现有滤波器、CANN、通信协议或拓扑策略。

当前正式安全基线仍为原有单星联邦-CI和多星分布式估计路径。导航CANN保持可关闭的sidecar；GNN/PPO在通过独立验收前不作为正式外协验收策略。

## 2. 通用测试原则

1. 算法对照必须共享真值轨迹、初始误差、过程噪声、量测噪声、可见性和随机种子。
2. 位置、速度和加速度的RMSE分别计算，不混合不同物理单位。
3. 改进率均使用配对运行计算，再跨场景和随机种子汇总。
4. 开发预扫描至少使用5个种子；正式验收建议至少使用20个种子，并报告95%置信区间。
5. 平均值之外必须报告最差节点、95%分位值和失败运行。
6. 仿真网络时延与软件墙钟处理延迟分开报告。
7. 可视化、CANN sidecar或数据记录开关不得改变算法状态、协方差和量测载荷。

## 3. 状态与误差定义

滤波状态保持六维位置—速度状态：

\[
x=[r_x,r_y,r_z,v_x,v_y,v_z]^T.
\]

加速度不扩展为独立滤波状态，而由估计位置通过当前动力学模型计算：

\[
\hat a_k=f_a(\hat r_k).
\]

对任一状态量 \(y\in\{r,v,a\}\)，全群全时段RMSE定义为：

\[
\operatorname{RMSE}_y=
\sqrt{\frac{1}{NK}\sum_{i=1}^{N}\sum_{k=1}^{K}
\lVert\hat y_{i,k}-y_{i,k}\rVert_2^2}.
\]

同时输出逐节点RMSE、终端误差、95%分位误差和最差节点RMSE。第7至第10项以位置RMSE作为主判定量，速度和加速度RMSE作为强制报告的非劣化辅助量。

## 5. 对照算法定义

### 5.1 P07单星Kalman基线

V1将“单星使用Kalman滤波方法”定义为同一六维轨道状态上的标准单星EKF：顺序处理同一组有效三模态量测，不启用CANN，不建立三个模态局部滤波器，也不执行联邦-CI。

待验单星策略使用三个模态局部估计及原有联邦-CI。量测侧CANN作为独立开关报告；导航CANN不参与该精度改进的归因。

\[
G_{single}=\frac{RMSE_{EKF}-RMSE_{single}}{RMSE_{EKF}}\times100\%.
\]

该定义需要在正式运行前通过项目方口径确认。若合同中的Kalman特指线性KF、单模态KF或其他实现，必须创建新版本基线，不得静默改变V1结果。

### 5.2 P09单星与多星对照

单星模式中每颗卫星独立运行，不接收邻星状态；多星模式启用星间相对观测、状态通信、Schmidt更新与回放，并使用冻结的确定性安全拓扑。两者共享20星物理条件和随机输入。

\[
G_{multi}=\frac{RMSE_{single}-RMSE_{cooperative}}
{RMSE_{single}}\times100\%.
\]

## 6. 鲁棒性场景

### 6.1 R08单模态缺失

正式主场景为单一模态全程缺失，并分别测试OPTICAL、INFRARED和RADAR。中段连续缺失与间歇缺失作为扩展场景。

\[
D_m=\frac{RMSE_{missing\ m}-RMSE_{full}}
{RMSE_{full}}\times100\%\le20\%.
\]

### 6.2 R10节点失联

20星中选择4星，失联窗口内删除这些节点的所有入站和出站通信边，本地传感器与本地滤波继续运行。至少覆盖同轨道面连续节点、跨轨道面分散节点、高中心性节点和随机节点组合。

\[
D_{node}=\frac{RMSE_{disconnected}-RMSE_{normal}}
{RMSE_{normal}}\times100\%\le15\%.
\]

分别报告全群、失联4星及其余16星的误差。20%随机丢包不能替代20%节点失联测试。

## 7. 更新频率与同步延迟

P06采用0.2 s外部滤波步长，在20星、三模态和正式多星策略下运行。计时排除GUI刷新和录像写盘，并分别报告无CANN、代表节点CANN和全节点CANN配置。

至少输出平均、P95、P99、最大单历元耗时、超过200 ms的历元比例和实时因子。合同硬判定使用平均更新频率：

\[
f_{mean}=\frac{K}{T_{wall}}\ge5\ \mathrm{Hz}.
\]

P11使用单调墙钟，在消息产生和接收端完成状态应用处埋点：

\[
L_i=t^{applied}_i-t^{created}_i,
\qquad \overline L\le150\ \mathrm{ms}.
\]

同时报告P95和最大延迟，并区分普通更新、历史回放和显式重同步。配置中的秒级仿真链路时延属于故障条件，不等同于软件处理延迟。

## 8. 第一版正式测试矩阵

- 规模：5、10、20星；核心合同项以20星判定。
- 时长：开发预扫描120 s；正式测试1200 s或1800 s。
- 步长：精度矩阵使用冻结配置；P06固定使用0.2 s。
- 构型：固定Walker基线和随机化Walker扩展集。
- 种子：开发5个；正式不少于20个。
- 条件：正常、三类单模态缺失、单/双导航失效、20%节点失联、丢包、时延、链路恢复和组合退化。

1. 将本文件和机器可读阈值作为V1基线评审冻结。

## 11. P07首轮开发预扫描

现有配对入口为：

```bash
python -m experiments.run_external_single_accuracy_acceptance \
  --seeds 0 1 2 3 4 --duration 120 --dt 2 \
  --output results/external_acceptance/p07_single_accuracy_prescan_120s
```

集中式EKF与联邦-CI对每个seed重新生成同一确定性真值和同一量测实现，均关闭CANN且不注入模态缺失。初查发现历史单星构型中的目标位于光学相机负深度方向，导致光学量测全部被可见性规则标记为无效；该结果不能称为三模态验收。P07入口因此显式采用目标处于正SPRI深度的配对构型，同时保留历史实验的默认构型不变。

修正后的首轮5种子、120 s三模态开发预扫描得到：

- 平均位置RMSE改进率约为-2.242%，未达到5%阈值；
- 近似95%半宽约为3.507个百分点；
- 5个种子中1个改善、4个退化，逐种子改进率约为+2.313%、-0.111%、-0.502%、-6.124%和-6.788%；
- 初始三分之一时段平均位置改进约为+0.853%，稳定时段约为-12.925%；
- 平均速度RMSE改进率约为+16.971%；
- 平均加速度RMSE改进率约为-1.471%；
- 三模态NIS均有限，两条架构的硬拒绝计数均为0；
- 联邦-CI平均权重约为光学0.634、红外0、雷达0.366。

进一步读取CI反馈前的局部后验后，三条支路的平均位置RMSE约为光学16.05 m、红外18.60 m、雷达17.96 m；平均协方差迹约为光学804.01、红外954.13、雷达940.39。trace-CI优先选择光学、排除红外与这一协方差排序一致，暂未发现明显的权重实现错误。滤波器原有reset feedback会在融合后覆盖公开局部历史，本轮仅增加融合前历史的只读诊断副本，不改变运行状态。

该结果只属于开发预扫描，样本数未达到正式20种子要求；但现有证据明确不支持宣称P07已经通过。当前主要问题不是量测拒绝或CI权重程序错误，而是比较定义本身：在同一量测噪声相互独立且模型已知的仿真中，集中式EKF可以联合累积三模态信息，CI则必须对未知相关性保持保守，理论上不应预期CI稳定优于前者。正式扩大运行前必须确认合同中的“单星Kalman”究竟指单模态传统KF，还是使用相同三模态的集中式EKF；不得仅为达到5%阈值调整算法或测试口径。

作为并列合同口径，入口随后加入仅光学、仅红外、仅雷达三个集中式EKF，并以每个配对seed中RMSE最低的单模态结果作为严格参考。相同5种子、120 s预扫描中，最佳单模态全部为光学；三种单模态平均位置RMSE分别约为光学28.22 m、红外42.72 m和雷达71.49 m，联邦-CI相对逐seed最佳单模态的平均位置RMSE改进约为41.93%，5个seed全部超过5%阈值。近似95%半宽约为16.37个百分点。该结果达到数值阈值但未满足正式20种子样本门，因此`threshold_met=true`而`passed=false`。

这组结果说明“多模态策略相对单模态Kalman”具有较充分的初步可行性，而“联邦-CI相对同信息三模态集中式EKF”不具备同样结论。两种口径必须在报告中并列保留，最终合同判定仍需项目方确认Kalman基线含义。

## 12. P08首轮开发预扫描

P08使用与P07相同的正深度构型、联邦-CI和5个配对seed，CANN保持关闭。每次将一种模态从0 s至120 s全程标记为无效，并与同seed完整三模态结果比较：

```bash
python -m experiments.run_external_single_robustness_acceptance \
  --seeds 0 1 2 3 4 --duration 120 --dt 2 \
  --output results/external_acceptance/p08_single_robustness_prescan_120s
```

首轮位置RMSE增幅为：

| 全程缺失模态 | 平均增幅 | 近似95%半宽 | 最差seed | 20%阈值 |
|---|---:|---:|---:|---|
| 光学 | 98.02% | 48.26个百分点 | 166.61% | 未达到 |
| 红外 | 约0% | 约0个百分点 | 约0% | 达到 |
| 雷达 | 90.20% | 64.52个百分点 | 212.35% | 未达到 |

该结果与P07的CI权重一致：完整三模态融合主要使用光学和雷达，红外平均权重为0，因此移除红外没有可测影响；光学与雷达之间仍存在显著互补，移除任一都会退化。当前结果不支持宣称P08通过。

全程缺失场景下，CANN不能生成新的独立信息，不能预期依靠短期状态保持将120 s退化压缩到20%以内。下一步应先检查合同中的“单一观测模态缺失”是全程缺失还是有限时段中断，并在不改变主判定记录的前提下，对CI目标、局部滤波可观测性和有限缺失时长进行专项扫描。

### 12.1 有限缺失与CI策略扫描

3个种子、120 s场景进一步扫描10/20/40/60 s中段缺失、trace/logdet目标和reset-feedback开关。现行默认reset-feedback开启时，两种CI目标下所有模态和所有扫描时长的平均位置RMSE增幅均不超过20%；trace目标的最大平均增幅约为缺光学60 s时的8.50%，logdet目标的最大平均增幅约为缺雷达20 s时的8.11%。个别负增幅属于短样本噪声波动，不解释为缺失改善性能。

关闭reset feedback后，缺雷达10/20/40/60 s的平均增幅在trace目标下约为23.71%、46.13%、65.68%和82.52%，均超过阈值；缺光学在60 s时也超过阈值。logdet呈现相同趋势。因此现有证据表明局部滤波器每历元接收融合反馈是有限缺失鲁棒性的关键机制，而trace与logdet差异较小。

当前应并列保留两项结论：现行默认架构初步满足最长60 s的有限时段单模态中断，但不满足120 s全程缺失。正式合同验收必须先确认“缺失”的持续时间或占空比；在此之前不得用有限时段结果替代永久缺失结果。

### 12.2 量测侧CANN边界审计

3个种子、60 s中段缺失的无故障配对中，缺失窗口内有无CANN的位置RMSE差严格为0，因为预处理器不会为无效量测合成替代观测。正常恢复阶段，光学和雷达CANN反而分别平均增加约0.62 m和1.10 m，红外差异可忽略。因此当前CANN不能作为P08纯缺失指标改善的依据。

在恢复后的前两个样本注入脉冲异常后，CANN体现出不同作用：无CANN时光学恢复异常带来的附加RMSE平均约3574.56 m，启用CANN后约0.75 m；雷达由约103.06 m降至约-1.35 m的短样本净变化，平均抑制约104.41 m。红外因CI权重接近0而没有可测影响。

因此量测侧CANN的已验证定位是“恢复异常抑制与可信重捕获”，不是“缺失信息预测或补全”。负的净异常代价属于配对短样本波动，不解释为异常改善精度。后续验收必须分别报告纯缺失、正常恢复和带异常恢复，不能合并成一个鲁棒性数字。

## 13. P09首轮开发预扫描

P09使用同一Walker 20/10/1场景进行严格配对。每个seed只生成一次真值、初始误差和绝对导航量测：单星独立组关闭全部星间相对量测和邻星状态消息，仅保留各节点自身动力学与绝对导航滤波；多星协同组启用现有RADAR、INFRARED、OPTICAL星间量测、Schmidt更新和精确事件回放。因此两组之间唯一的算法差异是协同信息链路。

```bash
python -m experiments.run_external_cooperative_accuracy_acceptance \
  --seeds 0 1 2 3 4 --duration 120 --dt 2 \
  --output results/external_acceptance/p09_cooperative_accuracy_prescan_120s
```

5个种子、120 s、2 s步长的开发预扫描结果为：单星独立组全群平均位置RMSE约1.645 m，多星协同组约1.468 m，逐seed改善率平均10.674%，近似95%半宽约2.517个百分点，最差seed改善7.801%。5个seed均超过5%数值门限，因而`threshold_met=true`；但样本数未达到正式要求的20个seed，故`formal_sample_size_met=false`且`passed=false`。

全群均值改善不保证每一颗卫星均改善。100个配对节点样本中有24个节点退化、29个节点未达到5%改善；最明显的退化为seed 3的`sat_p01_s02`，约为-42.54%。同一seed中，协同组的最差节点RMSE约2.139 m，高于独立组约1.976 m。该现象不改变当前P09“全群平均RMSE”口径的预扫描结论，但正式报告必须同时保留逐节点和最差节点指标，后续还应检查受损节点、几何位置及其邻接关系。

逐节点第一层审计表明，当前持久拓扑中20个节点度数均为2，每个节点在120 s内均收到122条RADAR、122条INFRARED和122条OPTICAL有效量测，因此退化不能归因于少邻居或量测缺失。改善率与总体、雷达、红外、光学平均NIS的相关系数分别约为0.014、-0.013、0.100和-0.066，未呈现明显创新异常关系；与独立组初始性能水平的相关系数约为0.354，说明独立估计本来较好的节点更容易出现负收益。跨5个seed平均后，`sat_p01_s02`和`sat_p03_s01`仍分别约退化7.71%和5.71%，下一层诊断应重点检查这两个固定轨道位置的视线方向条件、邻星组合和分方向误差，而不应直接按全局NIS调门限。

第二层几何与时段分解进一步表明，全体节点改善率与平均邻星距离和两条视线夹角的相关系数仅约-0.076和-0.078，不能用单一距离或夹角解释退化。`sat_p01_s02`连接`sat_p02_s02`与`sat_p10_s01`，其退化主要集中在前1/3时段：初段平均约-20.83%，后2/3时段转为约+9.04%，且主要体现在径向误差，属于明显的初始化/收敛瞬态。`sat_p03_s01`连接同轨道面的`sat_p02_s01`与`sat_p04_s01`，初段和后段分别约-5.99%和-7.66%，同时沿轨与法向误差增加，属于持续性局部负收益。下一步应对`sat_p03_s01`分别执行逐邻边和逐模态消融，定位具体信息来源；对`sat_p01_s02`则优先检查启动阶段的邻星先验与首次回放，不应将两类退化混为同一问题。

### 13.1 `sat_p03_s01`定向消融

保持其余19个节点及其协同链路不变，只改变`sat_p03_s01`接收的邻星与模态。5个seed稳定时段的平均改善率为：完整三模态-7.66%，仅RADAR -7.64%，仅INFRARED约-0.01%，仅OPTICAL约0.00%；因此该节点的可见负收益几乎全部由RADAR相对距离/距离率更新决定，角度模态在当前约5000 km量级链路和噪声配置下基本不改变结果。

逐边结果不支持永久删除某一固定邻边：仅保留`sat_p04_s01`时平均为-4.94%，仅保留`sat_p02_s01`时平均为-10.10%，但不同seed中造成主要退化的邻边会互换。例如seed 0和3中保留`sat_p04_s01`可恢复到接近独立基线，而seed 1中同一选择仍退化约43.46%。这说明问题更像是“当前先验和几何条件下，某次雷达协同更新是否具有正净信息增益”，而不是静态节点编号本身有缺陷。后续应以预测协方差和量测Jacobian形成的预期信息增益或后验协方差变化作为确定性选边依据，并将NIS保留为异常门控；不应依据本轮结果硬编码删除某条边。

### 13.2 预测信息增益的判别能力审计

在不改变更新接受逻辑的前提下，针对`sat_p03_s01`的610次RADAR更新记录更新前活动协方差、增益、创新协方差，并计算理论位置协方差缩减量`trace(KSK^T)`及其相对先验位置协方差的比例；运行后才使用真值计算同一次更新前后的位置误差范数变化。真值误差仅用于离线审计，不进入滤波器或策略输入。

结果显示，预测协方差缩减比例与实际位置误差变化的相关系数仅约-0.041；低收益四分位与高收益四分位的瞬时误差变差比例分别约48.4%和49.0%，没有可用区分度。两条邻边的变差比例也均约50%，平均单次误差变化分别约-0.0048 m和+0.0013 m。该结果符合随机Kalman更新的性质：协方差缩减描述统计期望，不保证每次噪声实现都降低真值误差。

因此预测信息增益仍可作为资源受限时的候选边排序特征，但当前证据不支持把它直接作为“负更新拒绝门”。P09局部长期退化更可能来自有限样本下的更新序列累积以及绝对导航已较强时的边际收益波动。下一步应验证更长时长和更多seed下固定节点负收益是否持续，并比较全群均值、逐节点尾部和协方差一致性；只有持续存在统计性偏差时，才需要设计新的质量反馈或选边规则。

### 13.3 扩展样本与时长检查

20个seed、120 s测试中，单星独立与多星协同的全群平均位置RMSE分别约为1.645 m和1.467 m，配对平均改善10.812%，近似95%半宽1.289个百分点，最差seed仍改善6.735%。数值门限和20个seed样本量门限均达到，但正式时长门限未达到，因此运行器已修正为`threshold_met=true`、`formal_sample_size_met=true`、`formal_duration_met=false`、`passed=false`，避免把开发短测误报为正式验收。

该20-seed短测的400个节点配对样本中，99个节点退化、134个节点未达到5%改善。此前的`sat_p01_s02`跨seed均值回升至约+8.22%，确认其5-seed负值主要是小样本波动；`sat_p03_s01`回升至约+2.16%，但20次中仍有11次退化，属于高波动、低边际收益节点，而非明确的稳定负偏节点。

5个seed、600 s中间长测的全群平均改善为9.971%，近似95%半宽1.965个百分点，最差seed改善6.797%。100个节点配对样本中22个退化、31个未达到5%，与120 s五种子时的24%和29%相近，说明逐节点尾部负收益不会仅靠延长到600 s完全消失。`sat_p03_s01`平均仍约退化0.86%，5次中3次退化，但幅度已经较小。当前证据支持“现有协同链路稳定改善全群平均误差”，不支持“每颗卫星均改善”。正式20 seed、1200 s测试应作为独立长批处理执行，并在结论中同时保留全群门限与逐节点尾部统计。
