# 在线多目标单机前序验收记录

## 1. 验收边界

本轮不包含跨设备HTTP/UDP联调，只验证同一进程中的完整在线算法路径：

1. 按1 s节拍生成雷达距离—多普勒图、红外图像和光学图像；
2. 从原始图像前端提取无标签三模态检测；
3. 自主短弧IOD、航迹新生、多目标关联和局部多模态滤波；
4. 目标级融合、身份保持、生命周期和类脑状态侧车；
5. 轨迹与显示JSON构造和序列化；
6. 使用完全相同的输入，对比关闭CANN与实时增量CANN。

输入图像生成耗时单独统计，不计入部署算法耗时。部署时这些帧由外部传感器或主系统提供。

## 2. 判定规则

- 所有预期目标完成IOD并在末帧保持活动；
- 无重复新生、身份交换和意外退役；
- 最终最大位置误差不超过2 km开发门限；
- 算法处理与JSON序列化总耗时P95不超过1 s；
- 超过1 s的帧比例不超过5%。

本轮在线GNN关联使用50 m位置、0.25 m/s速度预测不确定度下限。它只参与关联创新协方差，不修改滤波后验。该值是5/10/20/30/50/100/200 m受控扫描中，能够同时保持5节点3目标和10节点2目标航迹的最小稳定档位。

## 4. 本轮发现并修复的问题

原GNN仅传播 `F P F^T`，在高精度图像量测和多节点融合后可能低估一步预测模型误差。5节点3目标时表现为一条正确检测的平均马氏距离约43，超过13.82门限；10节点2目标时会进一步触发旧航迹退役和重复IOD新生。

修复采用独立的关联预测不确定度下限，而不是放大滤波协方差或取消门限。错误目标的代价仍比正确目标高多个数量级，近目标无法可靠区分时仍由原有最小代价裕量转为歧义拒绝。

## 5. 当前结论与剩余工作

当前可以确认：5节点下2—3目标以及10节点下2目标的1 s单机在线路径已打通，实时增量CANN在本机开发预扫描中满足1 s节拍。5节点3目标连续60 s运行未观察到处理时间随历史长度持续增长；选定目标连续3帧全模态缺失后也保持原身份恢复。

本轮仍不是最终正式验收，后续在跨设备联调之前还应补充：

- 更长时段（至少数百秒）的内存、航迹和尾延迟稳定性；
- 漏检、虚警、连续遮挡、机动和模态异步组合场景；
- 5节点3目标与10节点2目标的更多独立随机种子；
- CANN与传统异常预处理器的公平对照；
- 代表性配置下的P50/P95/P99和最坏帧分阶段耗时剖析。

运行入口：

```text
python -m experiments.run_online_multitarget_local_acceptance \
  --observers 5 --targets 3 --duration 20 --dt 1 --seed 0 \
  --cann-profile realtime \
  --output results/online_multitarget_local_acceptance/summary.json
```
