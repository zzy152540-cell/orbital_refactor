# CANN 到 GraphObservation 的紧凑特征契约

## 1. 目标与版本边界

本契约用于筛选导航 CANN 可以提供给多星拓扑策略的节点级诊断量。当前只生成独立指标字典，不修改 `GraphObservation` 数据类，也不改变现行 `v15.0-policy-normalized` 张量维数，因此已有 GNN/PPO 数据集和检查点保持兼容。

完成统计审计后，如证据支持，再以新的张量 schema 版本接入；不得静默改变 `v15.0`。

## 2. 首批候选指标

| 指标 | 来源 | 含义 |
|---|---|---|
| `cann_direction_concentration` | 方向 Ring CANN | 方向活动集中度 |
| `cann_abs_direction_residual_rad` | 方向 sidecar | 方向预测/锚定残差绝对值 |
| `cann_rt_residual_norm_m` | RT sidecar | R/T 残差范数 |
| `cann_anchor_age_s` | 方向/RT sidecar | 两者较大的锚点年龄 |
| `cann_shadow_quality` | 影子质量层 | 当前只读质量 |
| `cann_delayed_feedback_quality` | 延迟质量层 | 避免同历元循环的延迟质量 |
| `cann_boundary_saturated` | 统一导航状态 | 方向/RT表示边界异常 |
| `cann_anchor_rejected` | RT锚定 | 锚点是否被创新门限拒绝 |
| `cann_reference_rebased` | RT滚动参考 | 当前历元是否重置局部参考 |
| `place_fine_scale_active` | 分层位置细胞 | 细层当前是否可信并启用 |
| `place_boundary_saturated` | 分层位置细胞 | 粗层或活动细层是否越界 |
| `place_scale_transition` | 分层位置细胞 | 当前历元是否发生尺度切换 |

所有指标均来自当前或历史状态，不读取真值、未来轨迹、反事实收益或oracle动作；数值有限且非负，可通过现有 `additional_node_metrics_by_node` 进入 `GraphObservation` 对象。

## 3. 明确排除

- 1272维粗细位置细胞完整活动：维数过大且是现有状态的确定性重编码；
- 解码相位和RT绝对值：现有估计状态与几何特征已经承载主要信息；
- 位置细胞峰值和熵：真实压力场景中与真值误差的相关性不稳定；
- CANN相对真值误差：仅能用于离线评价，部署时不可得；
- 未来误差、未来NIS和反事实动作收益：属于标签或奖励，禁止进入策略观测；
- bump width：与集中度在此前审计中近乎完全相关。

## 4. 接入原则

1. 当前适配器只构建候选指标，不改变现行策略网络；
2. 正常场景中恒为零或一的事件标志不能因此删除，必须在退化场景审计覆盖；
3. 对连续量使用固定物理尺度或 `log1p`，事件量保持0/1；
4. 每个字段必须配套缺失掩码，CANN关闭时不能把默认零误解为“健康”；
5. 新张量版本必须重新生成训练数据，旧检查点不得加载到新增维数模型；
6. 确定性策略默认不依赖这些字段，CANN关闭时仍严格恢复原路径。

## 5. 首轮正常场景筛选结果

30 s、5 s步长的当前默认20星Walker审计中：

- 12个候选指标中有6个连续指标发生变化；
- 标准化矩阵有效秩为3.34；
- 变化指标之间没有绝对相关系数达到0.98的特征对；
- 所有节点与历元均有效；
- 6个事件指标在正常场景恒定。

连续变化组为方向集中度、方向残差、RT残差、锚点年龄、当前影子质量和延迟质量。它们保留为首批数值候选，但有效秩低于数量，后续训练前仍应通过消融判断质量变量是否重复。

正常场景恒定组为导航边界饱和、锚点拒绝、参考重定位、位置细胞细层启用、位置细胞边界饱和和尺度切换。它们属于低频安全事件，不能依据正常样本方差为零而删除；数据采集必须包含越界、失锚和重定位样本，否则模型无法学习其作用。

## 6. 当前接入决策

当前代码支持按严格对齐的决策时间提取每颗星的12项指标字典，并可由调用方传入 `build_online_graph_observation(..., additional_node_metrics_by_node=...)`。这只会把指标保存在 `GraphObservation` 中；现行 `v15.0` 张量白名单仍会忽略它们。

因此本节点不改变任何已训练模型。下一节点若创建 `v15.1`，应把12项指标加入新的节点白名单，由现有机制自动生成逐字段可用性掩码，并重新生成数据与训练检查点。

## 7. `v15.1-cann` 可选张量

独立函数 `tensorize_v15_cann_policy_observation` 先调用原 `v15.0` 张量器，再在节点特征尾部追加12个CANN指标和12个逐字段可用性掩码。原有节点、边和全局列的名称、顺序和数值保持不变。

连续量归一化规则为：

- 方向残差除以 π；
- RT残差使用 `log1p(residual / 100 m)`；
- 锚点年龄使用 `log1p(age / 10 s)`；
- 集中度与两个质量量保持[0,1]值；
- 安全事件保持0/1。

缺失CANN值编码为0，同时相应可用性掩码为0。新张量schema为 `v15.1-cann-policy-normalized`。旧 `tensorize_v15_policy_observation`、`v15.0-policy-normalized` 数据集和模型路径未修改；任何使用新张量的训练都必须创建新的数据版本与检查点。

## 8. 在线闭环模式

`TopologyControlEnvironment` 新增默认关闭的 `cann_policy_features` 开关。开启后，每颗星维护独立且持久化的方向、径向、RT与分层位置细胞状态。每个滤波历元完成后，sidecar读取当前估计状态和协方差，按固定周期执行可信软锚定，并生成下一次拓扑决策使用的12项指标。

因果顺序为：

```text
本历元滤波完成
→ 更新只读CANN sidecar
→ 构建带CANN指标的GraphObservation
→ 生成v15.1-cann张量
→ 选择下一步拓扑动作
```

CANN输出不会返回本历元滤波器；锚点在绝对导航失效时停止；输入只来自在线估计状态、协方差和配置，不读取仿真真值。默认关闭时环境继续调用原 `v15.0` 张量器。

## 9. 成对闭环回归结果

使用相同seed分别运行CANN关闭和开启的3星、7历元、always-keep短环境，得到：

- 每个历元的滤波状态和协方差完全一致；
- 奖励项与通信、丢包、回放、重同步和切换成本完全一致；
- `v15.1-cann` 的原 `v15.0` 节点特征前缀逐值一致；
- 全部动作合法且没有安全回退；
- CANN新增特征随历元变化；
- 导航失效节点在失效窗口内停止CANN软锚定，锚点年龄随之增长。

本机墙钟时间从关闭时约0.134 s增加到开启时约1.253 s，即3星配置附加约0.160 s/历元。这是当前未优化Python版方向、径向、RT及粗细位置细胞全部运行的开销，不代表最终实现。闭环正确性已经成立，但在扩大到20星训练前应评估降采样、仅决策历元更新位置细胞或压缩神经元数量。

## 10. 在线数值开销审计

函数级 profiling 表明，当前在线附加开销几乎全部来自方向 Ring CANN：3星、7历元短闭环中，CANN 新增约1.37 s，其中 Ring CANN 积分累计约1.34 s。每个2 s物理历元按1 ms内部步长积分，产生约3.76万次循环卷积和约7.52万次FFT调用。Line CANN、RT和位置细胞不是本轮首要瓶颈。

保持原微分方程和显式Euler稳定性约束不变的首轮扫描结果如下：

| 配置 | 总闭环时间 | 相对180神经元/1 ms | CANN特征最大偏差 |
|---|---:|---:|---:|
| 180神经元，1 ms | 1.525 s | 基准 | 0 |
| 180神经元，2 ms | 0.855 s | -44.0% | 0.00126 |
| 90神经元，2 ms | 0.775 s | -49.2% | 0.00126 |
| 60神经元，2 ms | 0.726 s | -52.4% | 0.00126 |

所有候选配置均保持滤波状态、协方差和`v15.0`张量前缀逐值一致。进一步在3/5星30历元正常、随机初始化和通信退化场景验证后，90神经元/2 ms获得约45%至51%的总闭环加速，最大特征偏差不超过0.001273；20星Walker短扫描获得约47.5%的加速，最大偏差约0.00125。因此在线拓扑侧车采用90神经元/2 ms作为工程默认。通用Ring CANN及独立科研实验的180神经元/1 ms基线保持不变，60神经元配置仍仅作为更激进的对照。

“只在决策历元更新”并未显著解决开销：决策间隔为3时仅降低约3%，因为一次较大的物理时间跨度仍会按内部步长完整积分，并且最大特征差异达到约0.288。因此该模式不作为默认路径；它只保留为显式消融选项。

## 11. 首轮配对数据与GNN消融

`v15.1-cann`快照数据使用与`v15.0`相同的反事实动作标签。基线视图直接截取同一张量的旧特征前缀，不重新运行仿真，因此两组输入不存在标签噪声或场景差异。首轮五星、多模态、随机物理构型、通信退化pilot共包含36个决策图和726个合法动作。

12项CANN数值特征中有6项在样本间变化；方向集中度、方向残差、RT残差和当前/延迟影子质量与动作收益跨度呈现中等样本相关，但这只是筛选信号，不代表因果关系。边界饱和、锚点拒绝、参考重定位、位置细胞尺度事件等6项仍为常数，说明普通拓扑和绝对导航失效随机化没有覆盖CANN内部失锁或表征边界事件。

相同训练/验证划分和3个网络随机种子的配对GNN消融中：平均oracle regret由`v15.0`的约0.0479变为`v15.1-cann`的约0.0522；精确动作命中率由约8.3%变为约5.6%；动作类型命中率由约72.2%变为约77.8%。结果具有明显种子波动，不能证明CANN特征带来稳定增益。

因此当前结论限定为：在线接口、张量版本和配对评估链路已经打通，但CANN特征尚未满足进入正式GNN/PPO输入的证据门槛。下一轮应显式构造长失锚、模型漂移、残差累积、边界接近和重定位事件，再进行同样的配对消融；在此之前`v15.0`仍是正式策略输入基线。

## 12. CANN事件压力校准

在线侧车现已允许显式传入方向、径向、RT和分层位置细胞配置，但这些配置仍只影响CANN表示，不改变滤波器。压力校准采用相同滤波场景成对运行，并缩窄局部表示范围或调整创新门限，以确认事件字段来自真实状态机路径而不是人工修改输出。

3星、12历元校准结果为：名义配置没有事件；窄RT/严格创新门限产生39次边界饱和和18次锚点拒绝；启用窄RT滚动参考产生5次参考重定位；窄位置支持域产生39次位置边界事件。全部压力配置与名义配置的滤波状态和协方差逐值一致。位置细胞尺度切换尚未被该组轨迹触发，不能以持续越界代替尺度切换样本。

这些校准配置只证明事件通路可观测，不直接证明事件与拓扑动作收益相关。正式压力数据必须进一步让长失锚、估计不确定性增长或模型失配与未来拓扑收益形成物理联系；不得仅通过缩窄编码范围制造事件后将其解释为策略信息增益。

## 13. 默认表示下的物理长失锚pilot

环境支持显式指定逐节点绝对导航失效窗口。该入口作用于原绝对导航可用性和CANN软锚定许可，不修改CANN编码范围，也不直接修改滤波状态。首轮物理压力场景令两颗星在2 s至20 s期间失去绝对导航，并保留三模态星间量测、随机物理构型、异构丢包/时延和动态链路事件；决策快照覆盖失效早期、失效中期和恢复后。

6个独立物理种子形成18个决策图。影子质量、延迟质量和锚点年龄与动作收益跨度的样本相关系数分别约为0.59、0.59和-0.61。相同标签、相同种子划分下的3次GNN初始化均使CANN版本的oracle regret下降，平均由约0.0760降至0.0419；精确动作命中率由0提升至约16.7%，动作类型命中率由约22.2%提升至约77.8%。

该结果支持扩大物理长失锚验证，但尚不构成正式接入证据：验证集仅含6个图，且当前样本的oracle动作全部为非keep，无法验证策略对“无需重构”的识别能力。下一轮需扩大种子数、随机化失效节点/起止时刻并加入keep占优对照；只有跨种子均值、方差和动作类型分层结果稳定后，才考虑把`v15.1-cann`用于GNN预训练或PPO观测。

## 14. 标签风险与keep失衡

快照标签原先只使用单次未来噪声下的位置RMSE改善。现已增加与PPO Stage-1一致的成本感知变换：通信、拓扑切换和重同步分别使用0.0025、0.001和0.001权重，并按4、1和2归一化；所有成本都相对keep计算，因此keep效用严格为0。当前样本在该权重下仍全部由非keep动作占优，说明现行成本权重相对单步RMSE变化较小，不能单独消除标签偏置。

全连接remove对照在12个单噪声图中仍全部选择remove。对4个条件、每个条件4个未来噪声进行均值聚合后，remove仍占优，但平均收益从单噪声约0.0368降至约0.0141，证明单噪声确有明显乐观选择偏差。进一步以“均值减去风险系数乘标准差”构造下置信界时，风险系数不超过1.4仍无keep，1.5时keep占75%，1.6及以上时keep占100%。

该转折仅来自4个条件，不能据此固定风险系数。后续必须在更多条件上校准下置信界系数，并报告keep/add/swap/remove分层比例、收益间隔和跨噪声稳定性。CANN与非CANN的GNN消融必须共享同一组鲁棒成本感知标签，避免把标签风险选择与CANN信息增益混为一谈。

## 15. 分层鲁棒风险扫描

扩展数据包含12个全连接remove对照、8个稀疏正常条件和12个长失锚决策条件，共32个鲁棒决策图。每个条件使用3或4个未来噪声分支生成收益均值与标准差。风险系数扫描继续使用PPO Stage-1成本权重，并按“收益均值减去风险系数乘标准差”构造动作标签。

合并结果中，风险系数为1.0时keep/add/swap/remove占比约为31.3%/12.5%/21.9%/34.4%；系数为1.2时约为37.5%/9.4%/18.8%/34.4%；系数为1.4时约为40.6%/9.4%/15.6%/34.4%；系数为1.5时keep骤升到约71.9%，remove降至约6.3%。因此1.2作为当前消融用候选，能够保留全部四种动作，但尚未固定为工程常数。

在跨场景、条件种子隔离的1.2风险标签下，3个网络随机初始化中，`v15.1-cann`相对`v15.0`有2次改善、1次持平。平均oracle regret由约0.00280降至约0.00238，平均精确动作和动作类型命中率均由约35.7%升至约54.8%。

该正向证据仍需特征子集对照：`v15.1-cann`同时增加连续CANN量、低频事件量和可用性掩码，网络输入维数及初始化也随之变化。下一步必须比较“仅6项变化连续量”“完整CANN字段”和“同维零占位”三组，确认改善来自CANN信息而不是额外参数或随机初始化。
